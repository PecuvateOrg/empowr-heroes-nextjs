# Skills

This file catalogs the reusable skills and slash commands available in this project.

## Available Skills

| Skill | When to use |
|---|---|
| `/netlify-deploy` | Deploy to Netlify and configure `hero.empowrcic.org` |
| `/pre-deploy-security` | Run before any deploy — FAILs block the deploy |
| `/webapp-testing` | Test UI with Playwright after frontend changes |
